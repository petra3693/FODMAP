# Reizdarm Étrend

6 hetes, alacsony FODMAP és fruktózszegény étrend napi és heti bontásban: receptek szerkeszthető mennyiségekkel és kalóriával, heti bevásárlólisták, tünetnapló, alapanyagcsere-számítás.

Egyetlen HTML fájl, telepítés nélkül fut. A kitöltött adatok csak a böngésző helyi tárolójában maradnak.
